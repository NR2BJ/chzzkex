# CHZZK EX
치지직의 재생·채팅·팔로잉 기능을 보완하는 Chrome·Firefox 확장 프로그램입니다.

- 음량 정규화
- 다이내믹 컴프레서
- 커스텀 라이브 타임라인
- 일시정지 후 실시간 기준 되감기 간격 유지
- Firefox에서 공식 클립 편집기 열기
- 시청 타이머 및 지연 표시
- 볼륨 퍼센트 표시
- 팔로잉 자동 갱신
- 사이드바 방송 미리보기
- 채팅 타임스탬프 및 지연 표시
- 투명 닉네임 및 블라인드 메시지 복구
- 통나무 파워 자동 수령
- 방송 재시작 시 음소거 자동 재생

외에 비밀 기능이 숨어있습니다
